## 📚 About

**French Tutor App** is a gamified language learning application designed to make learning French engaging, interactive, and fun. Whether you're a beginner just starting your French journey or an intermediate learner looking to polish your skills, this app provides an immersive learning experience with game mechanics that keep you motivated.

## ✨ Features

- 🎮 **Gamified Learning** – Earn points, unlock achievements, and climb the leaderboard
- 🗣️ **Interactive Lessons** – Engaging lessons covering vocabulary, grammar, and pronunciation
- 📊 **Progress Tracking** – Monitor your learning journey with detailed statistics
- 🎯 **Personalized Challenges** – Customized quizzes based on your learning level
- 🏆 **Rewards System** – Unlock badges and rewards as you progress
- 📱 **Responsive Design** – Learn anywhere on any device

## 🛠️ Tech Stack

- **Frontend:** TypeScript (97.5%)
- **Styling:** CSS (1.5%)
- **Markup:** HTML (1%)

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v14 or higher)
- **npm** (v6 or higher)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rgOptimize007/french_tutor_app.git
   cd french_tutor_app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to start learning!

### Build for Production

```bash
npm run build
npm run start
```
